# Designporten

Dette er det nye prosjektet for Designporten.no, etablert fra bunnen av som grunnlag for en komplett, moderne webplattform.

DESIGNPORTEN_MASTER.md er prosjektets overordnede spesifikasjon. Produkt, design, UX og arkitektur skal defineres før teknologistacken låses.

Prosjektet inneholder foreløpig kun dokumenter og mappestruktur. Ingen teknologi er valgt, avhengigheter installert eller funksjonalitet implementert. Eksisterende eller eldre Designporten-kode er ikke brukt som grunnlag.
