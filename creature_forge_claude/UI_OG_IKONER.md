# UI og ikonprinsipper

## Uttrykk
Lyst, rolig, inviterende og profesjonelt. Stor sentral 3D-arbeidsflate, lite visuelt støy. Ikke et mørkt, overfylt CAD-grensesnitt.

## Oppsett
- Nederst: delvis transparent tablinje med kategorier som «Kropp», «Tekstur/Farge», «Tilbehør».
- Kroppsdeler/struktur vises som sirkulære knapper (hode, overkropp, hofte, arm, ben, fot, hånd, hale). Valg kan åpne en ekstra rad med formvarianter.
- Kun **én undermeny åpen av gangen**.
- Features (øyne, nese, munn, ører, horn osv.) ligger i et eget sidepanel, ikke i nederste meny for kroppsstrukturen.
- Høyre egenskapspanel viser parametere for aktivt objekt/ledd/Feature.
- Manipulatorer vises kun for aktivt objekt. Symmetri og senterlinje kan aktiveres.

## Ikoner
- **SVG:** rene funksjonsikoner (flytt, roter, symmetri, synlighet, lås, lagre, angre osv.). Skalerbare, tematilpassede og konsistente.
- **3D-miniatyrer:** grunnformer, kroppsdeler, Features og ledd skal vises med faktiske geometriske modeller som appen genererer. Ikke tegn generiske symboler som utgir seg for å være eksakte modeller.
- Samme faste kameravinkel, mykt lys, sentrering og transparent bakgrunn for modellminiatyrer. Lag forhåndsvisning direkte i 3D, eventuelt cache i WebP/PNG.
- Det tidligere valgte ikonstilarket beholdes som visuell retning, med denne endringen for modellbaserte ikoner.

## Ressurser
`icons/svg/` inneholder noen originale enkle funksjonsikoner som utgangspunkt. De er ikke en rekonstruksjon av det tidligere 200-ikoners stilarket. Endelig ikonsett må tilpasses eksisterende Designporten-design og godkjennes.
