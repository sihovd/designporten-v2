# Feltmatrise: sidetekster → CMS

Ingen felt er fjernet: teksten i repoet blir standardteksten, og CMS-ets publiserte tekst vises over den. Listen lages på nytt ved hvert one.com-bygg, så nye felt kommer med automatisk.
